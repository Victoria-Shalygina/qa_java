Отчёт по работе с .gitignore

1. В проект добавлен .idea/ в .gitignore
2. Папка .idea удалена из репозитория командой:
   git rm -r --cached .idea

3. В .gitignore добавлена папка target/
4. Папка target (включая jacoco-отчёты) удалена из репозитория командой:
   git rm -r --cached target

5. Изменения закоммичены и отправлены в репозиторий
6. Проверено, что .idea и target больше не отслеживаются Git
